# AI智能改写模块 - 技术实现说明

## 📋 项目概述

本次开发完成了第三阶段AI智能改写模块的前端界面部分，实现了完整的分段式改写系统，集成李诞风格改写，提供高质量的内容改写服务。

## 🗂️ 文件结构

### 新增API方法 (`lib/api.ts`)
```
rewriteApi {
  ├── analyzeSegments()       # 文章分段分析
  ├── rewriteSegments()       # 分段改写
  ├── integrateSegments()     # 段落整合
  ├── evaluateQuality()       # 质量评估
  ├── getHistory()           # 改写历史
  ├── getStats()             # 统计信息
  ├── createBatchTask()      # 批量任务创建
  ├── getBatchTasks()        # 批量任务查询
  ├── updateBatchTask()      # 批量任务更新
  ├── cancelBatchTask()      # 批量任务取消
  ├── getConfigs()           # 配置管理
  └── updateConfig()         # 配置更新
}
```

## 📦 组件设计说明

### 1. SegmentPreviewCard - 段落预览卡片
**功能特性**：
- 显示段落原始内容和改写结果
- 支持编辑、改写、保存等操作
- 实时显示改写状态和质量评分
- 响应式设计，适配移动端

**核心Props**：
```typescript
interface SegmentPreviewCardProps {
  segment: SegmentData
  onEdit?: (id: string, content: string) => void
  onRewrite?: (id: string) => void
  onSave?: (id: string, content: string) => void
  onCancel?: (id: string) => void
  showRewritten?: boolean
}
```

### 2. RewriteProgressBar - 改写进度条
**功能特性**：
- 实时显示改写进度和状态
- 多阶段进度跟踪（分析→改写→整合→评估）
- 时间估算和统计信息
- 美观的视觉反馈

**状态类型**：
```typescript
type ProgressStatus = 'analyzing' | 'rewriting' | 'integrating' | 'evaluating' | 'completed' | 'failed'
```

### 3. QualityScoreDisplay - 质量评分展示
**功能特性**：
- 多维度质量评估展示
- 直观的评分可视化（进度条+分数）
- 改进建议和问题提示
- 评分标准说明

**评分维度**：
- 风格一致性 (styleConsistency)
- 内容完整性 (contentCompleteness)  
- 可读性 (readability)
- 总体评分 (overallScore)

### 4. StyleSelector - 改写风格选择器
**功能特性**：
- 4种预设改写风格选择
- 风格强度控制滑块
- 自定义改写要求输入
- 高级设置折叠面板

**支持风格**：
- 李诞风格 (推荐)
- 专业正式
- 轻松随意
- 学术严谨

### 5. RewriteComparison - 改写对比组件
**功能特性**：
- 原文与改写结果并排对比
- 统计数据可视化展示
- 两种查看模式切换
- 一键复制功能

**对比数据**：
- 字数变化统计
- 句子数量对比
- 段落结构分析
- 质量评分展示

## 🔄 核心业务流程

### 单篇改写流程
```
1. 用户选择素材
   ↓
2. 配置改写风格和参数
   ↓
3. 调用analyzeSegments API进行文章分段
   ↓
4. 显示分段结果，用户确认
   ↓
5. 调用rewriteSegments API进行分段改写
   ↓
6. 实时更新改写进度
   ↓
7. 调用integrateSegments API整合段落
   ↓
8. 调用evaluateQuality API评估质量
   ↓
9. 显示最终结果和对比分析
```

### 批量改写流程
```
1. 切换到批量模式
   ↓
2. 选择多篇文章
   ↓
3. 使用默认设置批量创建改写任务
   ↓
4. 后台处理，实时更新进度
   ↓
5. 完成后统一展示结果
```
