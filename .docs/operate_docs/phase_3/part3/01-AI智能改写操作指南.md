# AI智能改写功能 - 完整操作指南

## 📖 功能简介

AI智能改写功能已升级为**分段式改写系统**，结合李诞风格特色，提供高质量的内容改写服务。

### 🌟 主要特色
- **分段式改写**：避免整篇改写质量不均的问题
- **李诞风格集成**：融入专业的李诞式表达特色
- **智能质量评估**：多维度评估改写质量
- **实时进度跟踪**：全程可视化改写进度
- **批量处理支持**：一次性改写多篇文章

## 🚀 快速开始

### 第一步：进入改写功能
1. 在系统主界面点击左侧导航栏的**"AI改写"**按钮
2. 系统会自动打开改写功能界面

### 第二步：选择改写模式
改写功能提供两种模式：

#### 📝 单篇改写模式（推荐新手）
- 适合精细化改写单篇文章
- 可以详细查看改写过程和质量评估
- 支持手动调整和优化

#### 📚 批量改写模式（适合大量内容）
- 一次性改写多篇文章
- 适合批量处理素材
- 自动化程度更高

## 📋 详细操作步骤

### 🔸 单篇改写操作流程

#### 步骤1：选择素材
1. 在左侧**"素材选择"**区域查看可用素材
2. 点击任一素材卡片来选择要改写的文章
3. 系统会显示素材的基本信息（标题、来源、字数等）

#### 步骤2：配置改写设置
1. 点击**"改写设置"**标签页
2. 查看当前选中的素材信息
3. 在**"选择改写风格"**区域选择合适的风格：
   - **李诞风格**（推荐）：幽默犀利，语言简洁有力
   - **专业正式**：用词准确，逻辑清晰
   - **轻松随意**：语言活泼，贴近生活
   - **学术严谨**：措辞精准，论述严谨

#### 步骤3：调整风格参数
1. 使用**"风格强度"**滑块调整改写程度：
   - 30-50%：轻微调整，保持原文风格
   - 60-80%：适中改写，明显风格特征
   - 90-100%：强烈改写，突出风格特色

2. （可选）展开**"高级设置"**：
   - 在**"自定义改写要求"**中输入特殊需求
   - 例如："增加更多数据引用"、"使用更多比喻手法"等

#### 步骤4：开始改写
1. 确认配置后，点击**"开始分析分段"**按钮
2. 系统会自动分析文章结构并进行智能分段
3. 分析完成后，自动跳转到**"分段改写"**标签页

#### 步骤5：执行分段改写
1. 查看文章分段结果，每个段落都有独立的卡片显示
2. 点击**"开始改写"**按钮启动AI改写
3. 观察实时进度：
   - **进度条**显示整体完成情况
   - **时间估算**提供剩余时间预计
   - **段落状态**实时更新每个段落的处理状态

#### 步骤6：查看改写结果
1. 改写完成后，系统会显示**质量评估**结果：
   - **总体评分**：0-100分的质量评价
   - **风格一致性**：李诞风格的保持度
   - **内容完整性**：原文信息的完整保留度
   - **可读性**：文章的流畅度和易读性

2. 自动跳转到**"对比预览"**标签页查看结果

#### 步骤7：对比和确认
1. 在**"对比预览"**中查看：
   - **统计对比**：字数变化、句子数量、段落结构对比
   - **内容对比**：原文与改写结果的并排对比
   - **质量评分**：详细的评分分析

2. 支持两种查看模式：
   - **并排显示**：原文和改写结果同时显示
   - **标签切换**：在原文和改写结果间切换查看

### 🔸 批量改写操作流程

#### 步骤1：切换到批量模式
1. 点击左侧素材选择区域的**"批量改写"**按钮
2. 界面会切换为批量选择模式

#### 步骤2：选择多篇文章
1. 使用**"全选"**复选框快速选择所有文章
2. 或者逐一点击文章卡片进行选择
3. 已选择的文章会显示蓝色背景

#### 步骤3：开始批量改写
1. 选择完文章后，在选中提示区域点击**"开始批量改写"**
2. 系统会按照默认设置（李诞风格）进行批量处理
3. 批量改写会在后台自动进行，无需人工干预

## ⚠️ 重要注意事项

### ✅ 操作建议
1. **首次使用建议**：先尝试单篇改写模式，熟悉功能后再使用批量模式
2. **风格选择建议**：李诞风格适合大多数内容，专业内容可选择"专业正式"
3. **质量检查建议**：改写完成后务必查看质量评分和对比结果
4. **保存建议**：满意的改写结果及时保存到素材库

### ❌ 常见错误避免
1. **不要跳过设置环节**：直接开始改写可能效果不佳
2. **不要忽略质量评分**：低于70分的改写建议重新处理
3. **不要批量处理重要内容**：重要文章建议使用单篇改写模式精细处理

### 🔧 故障排除
1. **改写失败**：
   - 检查网络连接
   - 确认文章内容不为空
   - 重新尝试改写

2. **质量评分过低**：
   - 调整风格强度
   - 添加自定义改写要求
   - 选择更适合的改写风格

3. **进度卡住不动**：
   - 等待1-2分钟（AI处理需要时间）
   - 刷新页面重新尝试

## 📊 质量评分说明

### 评分标准
- **90-100分**：优秀 - 完美体现李诞风格，内容完整流畅
- **80-89分**：良好 - 风格明显，稍有改进空间
- **70-79分**：一般 - 基本达标，需要优化
- **60-69分**：及格 - 存在明显问题，建议重写
- **60分以下**：待改进 - 质量较差，需要重新改写

### 评分维度
1. **风格一致性**：李诞风格特征的体现程度
2. **内容完整性**：原文关键信息的保留程度
3. **可读性**：改写后文章的流畅度和理解难度

## 🎯 使用技巧

### 提升改写质量的技巧
1. **合理设置风格强度**：
   - 新闻类内容：50-70%
   - 评论类内容：70-90%
   - 娱乐类内容：80-100%

2. **善用自定义要求**：
   - "保持数据的准确性"
   - "增加更多生动的例子"
   - "使用更多口语化表达"

3. **分段策略选择**：
   - 短文章（<1000字）：建议整篇改写
   - 长文章（>1000字）：使用分段改写效果更好

### 批量改写优化建议
1. **分批处理**：一次不要选择太多文章（建议10篇以内）
2. **风格统一**：同类型内容使用相同风格设置
3. **后期检查**：批量改写完成后，重点检查质量较低的文章
