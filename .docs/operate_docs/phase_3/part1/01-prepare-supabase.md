# 步骤1：准备Supabase数据库

## 🎯 目标
在你的Supabase项目中执行SQL脚本，创建AI改写功能所需的数据库表。

## ⏰ 预计时间
5-10分钟

## 📋 前置条件
- 你已经有一个Supabase项目
- 项目的环境变量已经配置在`.env.local`文件中

## 🔧 操作步骤

### 第1步：打开Supabase控制台
1. 打开浏览器，访问 [supabase.com](https://supabase.com)
2. 点击右上角的 **Sign in** 登录你的账号
3. 在项目列表中找到你的微信内容管理项目，点击进入

### 第2步：进入SQL编辑器
1. 在左侧菜单中找到 **SQL Editor**（SQL编辑器），点击进入
2. 你会看到一个代码编辑区域，这里可以执行SQL语句

### 第3步：检查现有表
在继续之前，让我们先确认一下现有的表结构是正确的：

1. 在SQL编辑器中输入以下查询语句：
```sql
SELECT table_name 
FROM information_schema.tables 
WHERE table_schema = 'public' 
ORDER BY table_name;
```

2. 点击 **RUN**（运行）按钮

3. 你应该能看到类似这样的结果：
   - `articles` ✅（素材表）
   - `collect_sources` ✅（采集源表）
   - `collect_history` ✅（采集历史表）
   - 其他相关表...

如果看不到 `articles` 表，说明基础数据库还没有设置好，需要先完成前面阶段的工作。

### 第4步：准备执行脚本
现在你已经确认了数据库状态，可以进入下一步执行SQL脚本了。

## 🆘 遇到问题？

**问题1：无法登录Supabase**
- 检查网络连接
- 确认用户名和密码正确
- 尝试重置密码

**问题2：找不到项目**
- 确认你登录的是正确的账号
- 检查项目是否被误删除
- 联系团队其他成员确认项目状态

**问题3：看不到articles表**
- 可能是前面的开发阶段还没有完成
- 需要先完成素材管理和采集模块的数据库设置
- 检查.env.local文件中的数据库连接配置是否正确
