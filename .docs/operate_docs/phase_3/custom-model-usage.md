# 自定义模型使用指南

## 功能介绍

现在你可以手动输入任何OpenRouter支持的模型ID，不再受限于预设的模型列表。这样你就能：
- 使用OpenRouter上的免费模型
- 尝试最新发布的模型  
- 根据不同任务选择最合适的模型

## 使用步骤（初中生都能懂）

### 第一步：进入改写页面
1. 在导航菜单中点击 "AI改写"
2. 从左侧选择一篇要改写的文章

### 第二步：找到模型选择器
1. 点击 "改写设置" 标签页
2. 向下滚动到 "模型配置" 部分
3. 你会看到两个模型选择器：
   - 分段模型选择（用于智能分段）
   - 改写模型选择（用于内容改写）

### 第三步：切换到自定义模式
在任意一个模型选择器中：
1. 点击选择器顶部的 **"自定义模型"** 标签页
2. 现在你看到了一个输入框，可以输入任何模型ID

### 第四步：输入模型ID
有两种方法：

#### 方法一：使用免费模型快速选择
- 在输入框下方有几个绿色的免费模型按钮
- 直接点击任意一个免费模型按钮
- 模型ID会自动填入输入框

#### 方法二：手动输入模型ID
1. 在输入框中输入完整的模型ID
2. 格式必须是：`提供商名/模型名` 或 `提供商名/模型名:变体`
3. 例如：
   - `mistralai/mistral-7b-instruct:free`（免费）
   - `openai/gpt-3.5-turbo`
   - `anthropic/claude-3-haiku`

### 第五步：验证输入
- 如果模型ID格式正确，输入框下方会显示绿色的勾号
- 如果格式错误，会显示红色的错误提示
- 免费模型会显示绿色的礼物图标

## 使用技巧

### 1. 免费模型组合策略
- **分段用免费模型**：`mistralai/mistral-7b-instruct:free`
- **改写用免费模型**：`openchat/openchat-7b:free`
- 这样可以完全免费完成改写任务

### 2. 混合策略
- **分段用免费模型**：节省成本
- **改写用付费高级模型**：保证质量
- 在重要内容上投入，在辅助环节省钱

### 3. 测试新模型
- 在输入框中尝试最新的模型ID
- OpenRouter经常添加新模型，格式通常是 `provider/model-name`

## 注意事项

1. **模型ID格式**：必须严格按照 `提供商名/模型名` 的格式
2. **免费模型限制**：免费模型通常有使用频率限制
3. **模型可用性**：确保输入的模型ID在OpenRouter中确实存在
4. **API密钥**：需要在环境变量中配置 `OPENROUTER_API_KEY`

## 常见问题

**Q: 输入模型ID后显示红色错误？**
A: 检查格式是否正确，必须包含斜杠 `/`，例如 `openai/gpt-3.5-turbo`

**Q: 免费模型真的不要钱吗？**
A: 是的，带有 `:free` 后缀或标记为免费的模型完全免费使用

**Q: 如何知道更多可用的模型ID？**
A: 访问 [OpenRouter模型列表](https://openrouter.ai/models) 查看所有可用模型

**Q: 可以保存常用的自定义模型吗？**
A: 目前每次需要重新输入，建议把常用的模型ID记录在笔记本上

## 实际操作示例

假设你想使用免费模型完成一篇文章改写：

1. 进入改写页面，选择文章
2. 在分段模型选择器中：
   - 点击"自定义模型"标签
   - 输入：`mistralai/mistral-7b-instruct:free`
3. 在改写模型选择器中：
   - 点击"自定义模型"标签  
   - 输入：`openchat/openchat-7b:free`
4. 点击"开始分析分段"按钮
5. 完成分段后，点击"开始改写"

这样就能完全免费地完成AI改写任务！
