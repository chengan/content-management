# 🚀 智能文章内容获取功能

## 概述

这个功能解决了采集文章时只有标题和链接、没有完整内容的问题。现在系统可以自动获取文章的完整内容，让您的素材管理更加完善！

## ✨ 主要特性

- 🤖 **全自动获取**：采集后自动获取完整文章内容
- 🛡️ **安全防护**：智能防反爬，3-5秒间隔，避免被封
- 🔄 **智能重试**：失败自动重试，最多3次
- 👆 **手动控制**：支持手动触发获取
- 📊 **状态跟踪**：实时显示获取进度和状态
- 🎯 **批量处理**：支持批量文章内容获取

## 🏗️ 技术实现

### 核心组件

1. **ContentFetcherService** - 内容获取核心服务
2. **批量处理API** - `/api/content/batch-process`
3. **单篇获取API** - `/api/content/fetch`
4. **自动处理服务** - `/api/content/auto-process`

### 数据库扩展

新增字段：
- `content_status` - 内容获取状态
- `fetch_attempts` - 尝试次数
- `last_fetch_attempt` - 最后尝试时间

### 前端优化

- 素材列表显示内容状态
- 获取按钮和进度显示
- 状态指示器和动画

## 🎮 使用方法

### 基本使用流程

1. **正常采集文章**
   - 使用内容采集功能采集文章
   - 系统自动识别需要获取内容的文章

2. **自动内容获取**
   - 采集完成后自动触发内容获取
   - 系统后台按序处理，每篇间隔3-5秒

3. **查看结果**
   - 在素材管理页面查看获取状态
   - 完成后即可正常使用完整内容

### 手动操作

- **单篇获取**：在素材的更多操作中选择"获取内容"
- **状态查看**：查看文章标题旁的状态标签

## 📊 状态说明

| 状态 | 图标 | 含义 | 操作 |
|------|------|------|------|
| pending | 🟡 | 待获取 | 自动处理或手动获取 |
| fetching | 🔵 | 获取中 | 等待完成 |
| completed | ✅ | 已完成 | 可以正常使用 |
| failed | ❌ | 获取失败 | 可手动重试 |

## 🔧 API 接口

### 单篇获取
```
POST /api/content/fetch
Body: { articleId: "文章ID" }
```

### 批量处理
```
POST /api/content/batch-process
Body: { 
  limit: 5,           // 每批数量
  maxAttempts: 3,     // 最大尝试次数
  delayBetweenRequests: 3000  // 间隔毫秒
}
```

### 自动处理状态
```
GET /api/content/auto-process
```

## ⚙️ 配置参数

### 内容获取配置
- **请求间隔**：3-5秒（可调整）
- **最大尝试次数**：3次
- **超时时间**：30秒
- **并发数量**：2个

## 🐛 故障排除

### 常见问题

1. **获取失败率高**
   - 检查网络连接
   - 确认原文链接有效性
   - 降低并发数量

2. **获取速度慢**
   - 正常现象，为防止被封禁
   - 可适当调整间隔时间

3. **内容不完整**
   - 某些网站内容动态加载
   - 可能需要针对性优化

### 调试方法

1. 查看浏览器控制台日志
2. 检查API响应结果
3. 验证数据库状态字段
